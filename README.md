This is a cheat for the https://dialed.gg color game. Uses pyautogui to capture an image, and retrieves the HSL of the color. Then selects each setting for you. This bot has a 97.5% accuracy, easily placing you top 2000 in the world.

## Keybinds: 
### Capture Image - Right Shift
### Select Colors - Right Shift
(Runs 5 iterations before breaking out the loop.)
